# 앱 3.6.0 결과 화면

기준 시안·실제 캡처·차이 강조를 각각 탭으로 표시합니다.
선택한 탭의 이미지 하나가 전체 표시 폭을 사용합니다.
방향키와 Home·End 키로 탭을 선택할 수 있습니다.

확대와 화면 맞춤은 현재 표시하는 영역을 기준으로 적용합니다.
‘탭 간 위치 연결’을 켜면 같은 스크롤 위치로 이동하고, 끄면 탭마다 위치를 유지합니다.
PC·MO나 비교 결과를 바꿀 때 위치는 초기화하며 선택한 이미지 종류는 유지합니다.

## 유지하는 검수 기능

차이 목록, 이미지에서 차이 선택, 위치 강조, 판단 상태·심각도·메모 저장을 유지합니다.
통합 JSON 저장과 Chrome 확장 사용도 유지합니다.

## 화면에서 숨긴 항목

‘위치 보정과 재계산’, ‘구간별 수치와 캡처 정보’는 화면에서만 숨깁니다.
기존 데이터, 결과 생성, 보정 API와 화면 코드는 보존합니다.

## 보류한 소스 수정

앱의 HTML 열기·요소 소스 수정·소스 연결 진입점을 숨깁니다.
`app/web/app.js`의 `VisualQAFeatures.sourceEditing`이 `false`일 때 소스 편집기는 초기화하지 않습니다.
기존 편집기 파일과 서버의 소스 처리 코드는 남겨 둡니다.
추후 이 설정을 바꾸고 앱을 다시 시작하여 재사용할 수 있습니다.

실제 페이지에서 HTML·CSS를 수정하는 작업은 Chrome 확장에서 진행합니다.
