# 앱 3.5.1 · 확장 1.4.1 수정

## Mac 앱의 통합 JSON 저장

앱은 API 응답을 확인한 뒤 `blob:` 주소로 다운로드를 요청하지만, 기존 Mac WebView는 이 주소를 취소했습니다.
같은 앱의 정확한 로컬 출처에서 생성한 다운로드만 허용합니다.
외부 주소 이동과 다운로드가 아닌 blob 이동은 계속 차단합니다.

저장 창의 기본 폴더는 다운로드이며 사용자가 다른 폴더를 선택할 수 있습니다.
저장이 끝나기 전에는 완료 메시지를 표시하지 않습니다.
실패는 앱에서 안내합니다.

## 확장 갱신 후 남는 코드

새로고침 전의 오버레이 이벤트와 개발자도구 재연결이 유효하지 않은 Chrome API를 호출하는 오류를 수정합니다.
화면 변경, 이미지 해독 완료, 연결 종료 시 유효성을 확인하고 타이머·이벤트·비트맵·임시 주소를 정리합니다.
갱신된 패널을 다시 열어야 하는 경우 안내합니다.

이전 1.4.0 코드가 이미 실행 중인 페이지는 확장을 갱신한 뒤 한 번 새로고침합니다.
개발자도구의 수정 내용은 그 전에 저장합니다.

## 재현과 검사

기존 코드에서 Mac WebView의 JSON 취소와 확장 수명 관련 실패를 먼저 재현했습니다.
검사에 실제 Mac WebView 다운로드·출처 제한, 이벤트와 비동기 처리 중 확장 무효화, 실제 확장 새로고침 후 이전 코드 정리를 추가했습니다.
사용자 Chrome 프로필과 검수 자료는 자동 검사의 입력으로 사용하지 않습니다.
