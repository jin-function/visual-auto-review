# Chrome 시안 검수 v1.4.3

## 통합 검수 파일 연결

1. 검수 앱 v3.5.0 이상에서 PC·MO 검수를 실행합니다.
2. **PC·MO 통합 검수 파일**을 저장합니다.
   현재 선택한 대상의 비교 버전과 다른 대상의 최신 완료 버전이 함께 담깁니다.
3. Chrome 확장 관리에서 `chrome-extension` 폴더를 등록하거나 기존 확장을 새로고침합니다.
4. 확장 아이콘을 눌러 오른쪽 사이드패널을 엽니다.
5. JSON을 한 번 불러옵니다.
   등록 정보에서 PC·MO와 검수 폭을 확인합니다.
6. **현재 페이지에 연결** 또는 **실제 페이지 열기**를 누릅니다.

통합 파일에서는 PC·MO 파일을 별도로 선택하지 않습니다.
기본 기준은 1024px이며 검수 앱 프로젝트에서 설정한 전환 폭을 사용합니다.
브라우저 외곽 폭과 개발자도구의 기기 모드 안쪽 폭은 다를 수 있습니다.

## 검수 옵션

화면에 맞는 시안 하나만 표시합니다.
검수 폭보다 창이 좁아져도 자동 축소하지 않고 중앙을 기준으로 양쪽을 잘라 표시합니다.
시안이 현재 스크롤 범위 밖에 있으면 위치 이동이나 초기화를 사용합니다.

표시 여부·불투명도·위치·배율을 조절할 수 있습니다.
위치와 배율은 시안별로 저장되며 다시 연결한 뒤 복원합니다.
이 조정은 오버레이 위치 설정이며 검수 앱의 비교 판정을 다시 계산하지 않습니다.

**hidden 속성 제거**를 켜면 현재 페이지에 있는 `hidden` 속성을 미리보기에서 제거합니다.
앱이 이 설정을 담아 내보낸 통합 JSON을 불러오면 연결 시 자동으로 적용합니다.
확장에서 수동으로 바꿀 수 있으며, 파일을 다시 불러오면 파일의 설정을 다시 적용합니다.
옵션을 끄거나 검수 연결을 해제하면 확장이 제거한 속성을 복원합니다.
HTML 내보내기에도 미리보기 변경은 포함되지 않습니다.

상태에는 불러오기, 표시 중, 해당 시안 없음, 숨김, 화면 범위 밖을 구분해 보여줍니다.
파일에 PC 결과가 없으면 PC 화면에서 MO를 대신 표시하지 않습니다.
앱에서 PC 결과를 완료하고 통합 파일을 다시 저장하세요.

## 차이 항목과 수정

**차이 항목 · 요소 선택** 탭에서 목록을 누르면 해당 위치로 이동합니다.
앱에 기록한 판단·심각도·메모를 확인하고 검수 상태로 목록을 필터링할 수 있습니다.
이 기록은 파일을 저장한 시점의 사본입니다.

Chrome 개발자도구를 열고 **개발자도구에서 요소 선택**으로 Elements의 실제 요소를 선택합니다.
Elements와 Sources에서 HTML·CSS를 수정한 뒤 **수정한 HTML·CSS 저장**을 누릅니다.
사이드패널과 개발자도구의 ‘시안 검수’ 탭은 같은 도구를 사용합니다.

## 수정본 저장

- HTML·CSS는 원래 파일명을 사용합니다.
- 이름이 같은 CSS는 폴더로 구분합니다.
- CSS 원본 텍스트를 우선 사용해 주석·들여쓰기·줄바꿈을 보존합니다.
- 오버레이, 검수 도구, Five Server·Live Server 주입 코드는 내보내기 사본에서 제거합니다.
- HTML은 현재 DOM 사본이며 원본 소스의 서식과 다를 수 있습니다.
- 이미지·폰트·JavaScript는 원래 주소를 참조합니다.
- `manifest.json`에 원래 CSS 주소, 검수 묶음·대상·비교 버전, 앱·확장 버전을 기록합니다.

## 기존 파일과 업데이트

시안 원본이 들어 있는 v2 개별 JSON은 계속 읽습니다.
같은 실행·페이지의 개별 파일을 같은 묶음으로 관리하며, 나중에 추가한 파일도 기존 연결에 반영합니다.
다른 시안을 직접 연결해야 하는 이전 파일에는 고급 PC·MO 선택 기능을 유지합니다.
차이 강조 이미지가 들어 있는 v1 파일은 앱에서 다시 저장하세요.

앱 3.6.3과 확장 1.4.3을 함께 적용합니다.
Mac 앱에서는 통합 파일 저장 시 나타나는 저장 창에서 폴더를 선택합니다.
확장을 갱신한 뒤 검수 페이지도 한 번 새로고침하면 이전 버전의 남은 코드가 정리됩니다.
확장을 새로고침하기 전에 개발자도구의 수정 내용을 내보내세요.
새로고침 후 개발자도구를 다시 열고 현재 페이지에 연결합니다.
패널 상단의 확장 버전과 검수 옵션의 페이지 오버레이 버전이 일치해야 합니다.
