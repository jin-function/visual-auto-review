# 시안 검수 Chrome 확장 도구

기존 검수 결과 페이지에서 파일을 받고, 실제 페이지 위에 저장된 시안 원본을 겹칩니다.
HTML·CSS 수정은 Chrome 개발자도구에서 진행합니다.
Chrome 120 이상에서 사용합니다.

## 기존 버전에서 업데이트한 경우

`chrome://extensions`에서 시안 검수 확장 도구의 새로고침 버튼을 누릅니다.
검수하던 실제 페이지도 새로고침합니다.
확장 도구 아이콘을 누르면 Chrome 사이드패널이 열립니다.
검수 앱 v3.3 이상에서 **Chrome용 검수 파일**을 저장해 불러옵니다.
이미 시안 원본이 들어 있는 파일은 그대로 사용할 수 있습니다.
이전 JSON 파일에는 차이 강조본이 들어 있으므로 새 버전에서 오버레이로 사용하지 않습니다.
다운로드 기능 권한 확인이 표시되면 수정본 저장을 위해 허용합니다.

## 사이드패널 열기 오류가 표시되는 경우

`Cannot read properties of undefined (reading 'open')`은 사이드패널 기능을 사용할 수 없는 상태에서 열기 버튼을 눌렀을 때 발생하던 오류입니다.
v1.3.0에서도 기능을 확인하고 확장 백그라운드를 통해 패널을 엽니다.

확장 화면을 새로고침하면 **Chrome에 적용된 확장 버전**을 확인할 수 있습니다.
이전 권한 상태라면 **Chrome 확장 관리 열기** 버튼과 안내를 표시합니다.
버튼으로 이동한 확장 관리 화면에서 **시안 검수**의 새로고침 버튼을 누릅니다.
이후 확장 아이콘으로 도구를 다시 여세요.
또는 `chrome://extensions`에서 시안 검수 확장의 새로고침 버튼을 누릅니다.
권한 확인이 나오면 허용하고, 이미 열려 있던 개발자도구는 닫고 다시 엽니다.

검수 페이지의 HTML·CSS를 수정 중이라면 먼저 수정본을 저장하세요.
확장 관리 열기 버튼은 검수 페이지를 새로고침하지 않으며 원본 파일을 변경하지 않습니다.
페이지를 직접 새로고침하면 저장하지 않은 개발자도구 수정은 사라질 수 있습니다.

## 처음 한 번 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 설명서와 `manifest.json`이 들어 있는 **chrome-extension** 폴더를 선택합니다.
5. Chrome 도구 모음의 확장 프로그램 메뉴에서 **시안 검수 · 실시간 오버레이**를 고정합니다.
   이 아이콘으로 사이드패널을 열고 닫습니다.

GitHub 저장소를 내려받아 같은 폴더에 보관하세요.
설치 후에는 해당 폴더를 같은 위치에 보관합니다.
이미 열려 있던 개발자도구는 닫고 다시 열면 ‘시안 검수’ 탭이 표시됩니다.

## 검수하고 수정하기

1. 검수 앱에서 원하는 실행·화면 크기·비교 버전을 선택합니다.
2. **Chrome용 검수 파일**을 눌러 `visualqa-review.json`을 저장합니다.
3. Chrome에서 확장 도구 아이콘을 누르고 **검수 파일 불러오기**로 JSON 파일을 선택합니다.
4. **실제 페이지 열기**를 누릅니다.
   처음 사용하는 사이트라면 해당 사이트 접근을 허용합니다.
5. 실제 페이지에는 시안 원본을 겹쳐 표시하고, 도구는 Chrome의 **전용 사이드패널**에 표시합니다.
   도구가 검수 화면을 가리지 않으며 페이지의 HTML·CSS를 변경하지 않습니다.
6. macOS는 `⌘⌥I`, Windows는 `Ctrl+Shift+I`로 개발자도구를 열고 **Elements**에서 HTML·CSS를 수정합니다.
7. 사이드패널의 **차이 항목 · 요소 선택** 탭에서 목록을 누르면 해당 위치로 이동합니다.
   관련 요소를 고르고 **개발자도구에서 요소 선택**을 누릅니다.
8. 사이드패널에서 **수정한 HTML·CSS 저장**을 누릅니다.
   **저장 위치 선택**을 켜면 저장할 위치를 직접 고를 수 있습니다.
9. ZIP 파일을 압축 해제한 뒤 수정본을 확인하고 필요한 내용을 원본에 반영합니다.
10. 원본 반영 후 검수 앱에서 새 검수를 실행합니다.

현재 페이지를 그대로 사용하려면 그 페이지에서 개발자도구의 ‘시안 검수’ 탭을 열고 파일을 불러온 뒤 **현재 검수 탭에 겹치기**를 누릅니다.
다른 페이지 주소에는 겹치지 않도록 확인합니다.

개발자도구의 **시안 검수** 탭과 확장 도구의 별도 화면도 계속 사용할 수 있습니다.

## 검수 사이드패널

확장 도구 아이콘 또는 Chrome 패널의 닫기 버튼으로 도구 영역을 열고 닫습니다.
도구를 닫아도 실제 페이지의 시안 오버레이는 유지됩니다.
패널이 열리면 Chrome이 웹페이지에 사용할 수 있는 폭을 조절합니다.
확장은 실제 페이지의 CSS 뷰포트 폭으로 PC·MO를 자동 전환합니다.
모바일 검수는 개발자도구의 기기 도구 모음에서 검수 폭을 지정하면 같은 폭을 유지할 수 있습니다.
패널 위치는 Chrome의 사이드패널 위치 설정을 따릅니다.

**PC·MO 시안 연결**:

앱의 같은 실행에서 PC와 MO의 **Chrome용 검수 파일**을 각각 저장합니다.
사이드패널의 **검수 파일**에서 두 파일을 불러온 다음 현재 페이지에 연결합니다.
같은 실행·페이지의 시안은 자동으로 짝을 연결합니다.
다른 실행의 결과는 **검수 옵션**에서 PC와 MO 시안을 직접 선택하고 **시안 분기 적용**을 누릅니다.
자동 연결 시 파일에 PC·MO 정보가 없는 예전 v2 파일은 검수 폭 1024px을 기준으로 분류하므로 필요한 경우 직접 지정합니다.

기본 기준은 **1024px 이상 PC / 1024px 미만 MO**입니다.
**PC 전환 폭**을 바꾸면 다른 반응형 기준을 사용할 수 있습니다.
현재 폭에 맞는 시안이 미등록이면 오버레이를 숨기고 안내합니다.
반대 시안을 대신 표시하지 않습니다.
차이 목록과 관련 요소도 표시 중인 시안에 맞춰 바뀝니다.
X·Y 이동과 배율 보정값은 시안마다 따로 보존합니다.

캔버스는 최소한 검수 폭을 유지하며 창이 좁아져도 자동 축소하지 않습니다.
상단에 맞춰 화면 중앙에 놓이므로 좁은 창에서는 시안 양쪽이 잘려 보일 수 있습니다.
검수 시점과 같은 배치를 비교하려면 개발자도구에서 해당 검수 폭으로 맞춥니다.
직접 지정한 배율은 계속 적용됩니다.

**검수 옵션** 탭:

- **시안 원본 표시**: 시안 표시를 켜고 끕니다.
- **이미지 불투명도**: 실제 화면이 잘 보이도록 조정합니다.
- **X·Y 이동**: 실제 페이지에 겹친 이미지 위치를 조정합니다.
- **이미지 배율**: 명시적으로 선택한 배율을 적용합니다.
- **위치·배율 초기화**: 이동과 배율을 기본값으로 되돌립니다.

**차이 항목 · 요소 선택** 탭:

- **차이 항목 목록**: 제목·좌표·크기·관련 요소 수를 표시합니다.
  항목을 누르면 해당 위치로 이동하며 선택한 항목을 강조합니다.
- **이전 / 위치 이동 / 다음**: 차이 항목을 순서대로 확인하거나 현재 위치로 다시 이동합니다.
- **개발자도구에서 요소 선택**: 선택한 관련 요소를 Elements에서 선택합니다.

두 탭에서 공통으로 사용하는 도구:

- **수정한 HTML·CSS 저장**: 개발자도구에서 수정한 현재 상태를 ZIP으로 저장합니다.
- **검수 파일**: 파일 가져오기와 실제 페이지 연결 화면으로 돌아갑니다.
- **연결 해제**: 이 탭에서 이미지를 제거하고 자동 재연결을 중지합니다.

실제 페이지의 오버레이는 클릭과 요소 선택을 가로채지 않습니다.
활성 탭을 바꾸면 사이드패널도 그 탭에 연결된 검수 도구로 전환합니다.
요소 선택과 파일 저장에는 실제 검수 페이지의 Chrome 개발자도구가 열려 있어야 합니다.
현재 탭의 설정은 새로고침 후 다시 적용됩니다.
Chrome을 종료하면 탭 연결은 해제되며 불러온 검수 파일은 확장 도구 안에 남습니다.
**불러온 파일 제거**로 확장 도구에 보관한 파일을 지울 수 있습니다.
원래 앱의 검수 이력은 삭제하지 않습니다.

화면 폭이 검수 때와 다르면 안내를 표시합니다.
개발자도구의 기기 도구 모음 `⌘⇧M`에서 Responsive 모드의 폭을 검수 폭과 같게 설정하세요.
이미지 배율을 바꾸는 것만으로는 페이지의 반응형 배치가 일치하지 않습니다.
시안 원본의 픽셀과 크기를 보존하고 검수에 사용한 배율로 표시합니다.
배율 100%는 검수 당시 표시 크기를 뜻합니다.
오버레이 위치·배율 변경은 검수 앱의 판정이나 저장된 보정값을 변경하지 않습니다.

캡처 당시의 아코디언 상태와 현재 페이지 상태가 다르면 실제 페이지에서 해당 영역을 펼쳐 맞추세요.
확장 도구는 페이지의 아코디언 속성·스타일을 변경하지 않습니다.
검수 앱에 있던 아코디언 캡처 처리는 변경하지 않았습니다.

## 내보내는 파일

- `html/원래이름.html`: Elements에서 바꾼 내용을 포함한 현재 DOM 사본입니다.
- `css/원래이름.css`: 수정한 외부 CSS이며 원본 파일명을 유지합니다.
  같은 이름이 여러 개면 `css/source-2/원래이름.css`처럼 폴더로 구분합니다.
- `manifest.json`: 원래 URL과 내보낸 CSS 파일의 대응, 비교 버전, 오버레이 설정, 읽지 못한 항목을 기록합니다.
- `읽어주세요.txt`: 결과의 범위와 확인할 항목을 담습니다.

HTML은 실행 전 원본 소스와 구조·서식이 다를 수 있습니다.
인라인 스타일 수정은 HTML에 포함됩니다.
CSS는 개발자도구가 제공하는 수정된 소스 텍스트를 사용합니다.
원래 주석, 공백·탭 들여쓰기, 줄바꿈과 URL의 따옴표 형식을 보존합니다.
URL 값은 저장 위치에 맞게 조정하며 `@import`도 내보낸 파일을 가리킵니다.
페이지 스크립트가 추가한 CSS 규칙은 기존 소스를 유지하면서 반영합니다.
원본 텍스트가 없는 동적 스타일은 알림에 기록합니다.
CSS 규칙이 현재 페이지와 일치하지 않으면 저장을 중단하고 다시 저장하도록 안내합니다.

HTML에서는 확장 도구의 오버레이·패널·추가 스크립트·스타일과 Five Server의 주입 스크립트·강조 스타일·안내 마크업을 제거합니다.
페이지 자체의 스크립트, JSON-LD와 인라인 스타일은 보존합니다.
원본 페이지와 개발자도구의 수정 상태는 정리 과정에서 변경하지 않습니다.
ZIP 파일명도 HTML의 기본 이름을 사용합니다.
예를 들어 `page.html`의 저장 파일은 `page.zip`입니다.
이미지·폰트·JavaScript는 원래 주소를 참조합니다.
내보내는 HTML·CSS는 이 주소들을 유지하므로 로컬 서버가 필요한 경우 서버를 계속 실행하세요.
완전한 오프라인 사이트나 소스맵 원본인 SCSS 등을 생성하지 않습니다.
iframe·Shadow DOM 내부와 canvas의 그려진 내용은 HTML 사본에 포함되지 않으며 해당 경우 내보내기 안내에 표시합니다.

개발자도구에서 수정한 내용은 새로고침하면 사라질 수 있습니다.
새로고침 전에 파일을 내보내세요.
다운로드한 HTML과 CSS는 원본 파일에 자동으로 덮어쓰지 않습니다.

## 접근 범위

HTTP·HTTPS 페이지를 지원합니다.
로컬 HTML은 로컬 서버로 열어 검수하세요.
사이트 접근은 실제 페이지를 열거나 겹치기를 누를 때 해당 사이트에만 요청합니다.
검수 파일과 이미지, 수정한 HTML·CSS를 외부 서버에 업로드하지 않습니다.
다운로드 권한은 사용자가 누른 HTML·CSS 저장에 사용합니다.
기존 검수 앱의 로컬 인증과 다른 출처 요청 차단은 유지됩니다.
