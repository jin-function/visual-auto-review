# 통합 검수 리팩토링 검증

앱 3.5.0, 확장 1.4.0, 전달 규격 v3입니다.
Python 47개, JavaScript 16개 단위 검사와 Chrome 통합 흐름 69개를 통과했습니다.

실제 앱 HTTP 경로에서 생성한 통합 JSON을 Chrome에 불러와 PC·MO 원본 픽셀, 표시 상태, 검수 메모, 상태 필터, 보정 복원을 확인했습니다.
앱 화면에서 프로젝트 전환 폭을 바꾸고 새 검수 후 두 시안이 들어 있는 JSON을 한 번 내려받는 흐름을 확인했습니다.

기존 IndexedDB 이미지·메타데이터 분리 변환, 이전 세션 연결 변환, 나중에 불러온 개별 파일 반영, 잘못된 묶음의 저장 차단을 검사했습니다.
SHA가 맞아도 해독할 수 없는 PNG는 저장 전에 거부합니다.
구버전 확장은 `sidePanel.open` 오류 대신 업데이트 안내를 표시합니다.

HTML·CSS 내보내기의 원래 파일명, CSS 서식·주석·CRLF, 중복 파일명 폴더 구분, 검수 도구·개발 서버 주입 코드 제거 검사를 통과했습니다.
검수 앱의 아코디언 모듈은 변경하지 않았습니다.

테스트는 사용자 Chrome과 데이터 폴더 대신 임시 프로필·임시 데이터·테스트 이미지를 사용했습니다.
브라우저와 설치본 검증의 기계 판독 기록은 로컬 `verification/`에 보관하며 개인 검수 자료를 GitHub에 올리지 않습니다.
Windows 실제 브라우저 검증은 별도 확인 사항입니다.
