# Chrome 확장 v1.3.2 적용·PC/MO 전환 검증

## 확인된 사실

현재 검수 페이지에는 오버레이 DOM이 하나 있었으며 구버전의 표시 방식이 적용되어 있었습니다.
실제 사용 폴더에 남아 있던 확장은 v1.2.1입니다.
이 버전은 연결한 시안을 계속 표시하고 화면 크기에 따른 PC·MO 전환 기능이 없습니다.

별도 임시 Chrome에 v1.2.1을 불러와 재현했습니다.
PC용 검수 파일을 등록한 상태에서도 1200px로 넓히면 기존 모바일 시안이 계속 표시되었습니다.

## 수행한 변경

- 실제 사용 확장 폴더를 백업하고 최신 버전으로 갱신합니다.
  Chrome 확장 관리에서 새로고침하면 갱신한 파일이 적용됩니다.
- 오버레이의 버전 값을 실제 Chrome 등록 버전과 연결했습니다.
- 사이드패널에 확장 버전과 실제 페이지 오버레이 버전을 표시합니다.
- 현재 페이지에서 분리된 오버레이를 연결된 상태로 보고하지 않도록 했습니다.
- 기존 PC·MO 자동 분기와 미등록 시안 숨김 처리는 유지합니다.

## 검증 결과

- Node 단위 검사 13개 통과.
- Chrome 통합 흐름 57개 통과.
- PC는 빨간색, MO는 파란색 시안으로 구분해 실제 캔버스 픽셀을 확인했습니다.
- 1023px의 MO → 1024px의 PC → MO 복귀 시 해당 이미지로 전환됩니다.
- PC 파일이 없으면 MO 이미지를 대신 표시하지 않고 숨깁니다.
- 화면에 연결된 오버레이와 패널의 버전 표시가 일치합니다.
- 기존 파일명·CSS 서식 보존과 검수용 HTML 정리 검사도 통과했습니다.

환경은 macOS Intel, Node 22.21.0, Chrome for Testing 149.0.7827.55입니다.
검증에는 일반 사용자 프로필과 별개의 임시 프로필을 사용했습니다.
실제 사용 중인 Chrome에서는 확장 새로고침과 다시 연결이 필요합니다.
기기 모드의 페이지 폭이 390px이면 모니터나 브라우저 외곽 크기와 관계없이 MO를 표시합니다.
